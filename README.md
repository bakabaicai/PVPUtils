## Introduction

PVPUtils is a utility mod for Minecraft 1.21.11 Fabric. It brings a better experience to PVP, includes useful feature and beautiful visual.

## Features

PVPUtils includes many useful feature for PVP and beautiful visual. The mod groups them into several categories: Combat, Render, Tool, Optimize, Misc, and Theme.
These features include HUD display, block animation, motion blur, input method fixes (for chinese player), block count display, target information display, dymanic island, mouse tweak, zoom, etc. Download mod to see the full features.

## Disclaimer

PVPUtils is a client-side mod that does not modify server data or provide cheating features. Some servers may still prohibit it, so read their rules before use and accept all risks yourself.

## FAQ
1. The default keybind is `Right Shift`.
2. Press `P` on the title screen to switch to the custom title screen.
3. Language switching is located under `Misc -> Language Switch`. Right-click to expand it and switch between Chinese and English. Reopen the UI for the change to take effect.
4. This mod is currently not compatible with Lunar Client. Other third-party clients haven't been fully tested yet and might have issues.
5. Target health display may occasionally be inaccurate. This is usually caused by server plugin restrictions and cannot be fixed by the mod.
